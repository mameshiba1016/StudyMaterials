# 08 DirectX

DXライブラリ編の後、描画APIとGPU内部処理を低水準から学ぶ章です。

予定内容：Windows Application、COM、DirectX Math、DXGI、Adapter、Device、Swap Chain、Render Target、Depth Buffer、Viewport、Vertex／Index／Constant Buffer、Input Layout、Texture／Sampler、Rasterizer／Blend／Depth State、HLSL、Vertex／Pixel／Compute Shader、Model／Animation、Lighting／PBR、Shadow、Post Process、Instancing、Resource Lifetime、Upload、Synchronization、Frame Resource、Command Queue／List、Descriptor Heap、Root Signature、PSO、Barrier、GPU Debug、PIX、Renderer設計。

まずDirectX 11で描画Pipelineの各段階を確認し、その後DirectX 12でCPUとGPUの非同期実行、明示的なResource状態、Descriptor、Fence、複数Frame管理を扱います。
