# コードの読み方

## 左から眺めるだけではなく、役割へ分解する

```cpp
int playerHp = 100;
```

読み方は「イント型のプレイヤー・エイチピーを100で初期化する」です。

- `int`：型。値をどう解釈し、どの演算を許すかを定めます。
- `playerHp`：識別子。プログラマーが値を参照するための名前です。
- `=`：この宣言では初期値を指定する記号です。
- `100`：整数リテラル。ソースへ直接書かれた整数値です。
- `;`：文の終端です。

## 読むときの質問

1. この行は何を作るのか。
2. 入力となる値は何か。
3. どの値を変更するのか。
4. 結果はどこで使われるのか。
5. 作られたオブジェクトはいつ破棄されるのか。
6. 失敗、不正値、境界値の場合はどうなるのか。

## コードは上から必ず一行ずつ実行されるのか

単純な文は原則として順番に評価されますが、関数呼び出し、条件分岐、ループ、例外、並列処理によって制御の流れは変化します。またコンパイラは、外から観測できる動作を保つ範囲で命令を並べ替えたり削除したりできます。ソースの記述順とCPU命令の順序が常に同一とは限りません。
