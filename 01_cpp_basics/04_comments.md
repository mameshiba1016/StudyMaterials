# コメントの種類と書き方

## 行コメント

```cpp
// この行の//より右側はコメントです。
int score{0};
```

## ブロックコメント

```cpp
/* 複数行へまたがるコメントです。
   C++のブロックコメントは入れ子にできないため、コードの一時無効化には注意します。 */
```

## 良いコメント

コードを日本語へ直訳するだけでなく、**なぜ必要か、前提は何か、単位は何か、危険は何か**を残します。

```cpp
// ヒットストップ中もUIアニメーションは止めないため、ゲーム時間ではなく実時間を使用する。
uiElapsedSeconds += realDeltaSeconds;
```

## 避けたいコメント

```cpp
// hpから10を引く（コードを読めば分かり、設計意図がない）
hp -= 10;
```

代わりに、ダメージの由来や例外規則を型・関数・データ設計で表現し、必要な背景だけコメントにします。コメントはコードと同時に更新し、嘘になったコメントを残さないことが重要です。
