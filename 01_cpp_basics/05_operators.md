# 演算子

演算子は、値に対する計算、比較、代入、アクセスなどを表す記号です。同じ記号でも、オペランド（演算対象）の型や文脈によって意味が変わります。

## 算術演算子

```cpp
int attack{23};
int defense{8};

int sum{attack + defense};       // 加算。結果は31。
int difference{attack - defense}; // 減算。結果は15。
int product{attack * 2};         // 乗算。結果は46。
int quotient{attack / 2};        // 整数同士の除算。小数部を捨て、結果は11。
int remainder{attack % 2};       // 剰余。23を2で割った余りなので1。
```

`/`は常に小数を返すわけではありません。両辺が整数型なら整数除算です。

```cpp
int defeated{1};
int total{2};

// 先に整数除算が実行されて0になり、その後floatへ変換されます。
float wrongRate{defeated / total}; // 0.0F

// 一方を明示的にfloatへ変換すると、浮動小数点除算になります。
float correctRate{static_cast<float>(defeated) / total}; // 0.5F
```

0による整数除算・剰余は未定義動作です。浮動小数点の0除算は環境と値によって無限大やNaNなどになり得ます。ゲームの速度や正規化処理では、分母を事前に検査します。

## 代入と複合代入

```cpp
int hp{100}; // 定義時の初期化。
hp = 80;     // 既存オブジェクトへの代入。
hp += 10;    // hp = hp + 10; と同等の目的。結果は90。
hp -= 25;    // 結果は65。
hp *= 2;     // 結果は130。
hp /= 2;     // 結果は65。
hp %= 10;    // 結果は5。
```

複合代入は左辺を一度だけ評価します。関数呼び出しや添字アクセスを含む複雑な左辺では、単純な書き換えと完全に同じとは限らない点が重要です。

## インクリメントとデクリメント

```cpp
int comboCount{3};

++comboCount; // 前置。先に4へ増やし、その式の値も4。
comboCount++; // 後置。式の値は増加前の4で、処理後に5。
--comboCount; // 前置で4へ減少。
comboCount--; // 後置。式の値は4、処理後は3。
```

返り値を使わない単純な増減では差を意識する必要は小さいですが、イテレータなどでは後置が古い値のコピーを必要とする可能性があります。読みやすさのため、一つの式内で同じ変数を何度も増減させません。

## 比較演算子

```cpp
bool isDead{hp <= 0};       // 以下
bool canHeal{hp < 100};     // 未満
bool isFull{hp == 100};     // 等しい。=（代入）とは異なる。
bool isDamaged{hp != 100};  // 等しくない
bool isHigh{hp > 70};       // より大きい
bool isEnough{hp >= 50};    // 以上
```

浮動小数点数は丸め誤差を持つため、計算結果を安易に`==`で比較しません。用途に応じた絶対誤差・相対誤差、または範囲比較を使います。

## 論理演算子と短絡評価

```cpp
bool hasStamina{true};
bool isStunned{false};

bool canDodge{hasStamina && !isStunned}; // ANDとNOT。結果はtrue。
bool cannotAct{!hasStamina || isStunned}; // OR。どちらかがtrueならtrue。
```

`&&`は左辺が`false`なら右辺を評価せず、`||`は左辺が`true`なら右辺を評価しません。これを短絡評価と呼びます。

```cpp
Enemy* target{nullptr};

// targetがnullptrなら右辺を評価しないため、無効なポインタ経由のアクセスを避けられます。
// Enemy型の詳細はポインタの章で扱います。
if (target != nullptr && target->IsAlive())
{
    // 生存している有効な対象にだけ処理する。
}
```

## ビット演算子

`&`（AND）、`|`（OR）、`^`（XOR）、`~`（反転）、`<<`（左シフト）、`>>`（右シフト）は整数の各ビットを操作します。入力状態、衝突レイヤー、フラグなどに使われますが、論理演算子`&&`・`||`とは異なります。符号付き整数のシフトには難しい規則があるため、ビット操作では意図に合う符号なし整数型を慎重に使用します。

## 優先順位

演算子には評価のまとまりを決める優先順位があります。

```cpp
int resultA{2 + 3 * 4};   // 乗算が先なので14。
int resultB{(2 + 3) * 4}; // 丸括弧を先に評価するので20。
```

優先順位を暗記だけに頼らず、意図が読みにくい式には括弧と中間変数を使います。なお、**優先順位**と、複数の部分式が実際に評価される**順序**は別の概念です。
