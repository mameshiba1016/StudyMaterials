# 型・変数・初期化

## 型とは

型は単なる箱の大きさではありません。ビット列の解釈、許可される操作、初期化・コピー・破棄の方法、アラインメントなどを決める規則です。

```cpp
// 符号付き整数。サイズは処理系依存であり、常に32ビットとは規格上保証されません。
int hitPoint{100};

// 単精度浮動小数点数。多くの小数は二進数で正確に表せないため近似値です。
float moveSpeed{5.0F};

// 真偽値。条件式に使用できます。
bool isAlive{true};

// 一文字分の文字コード単位を保持する型。文字列そのものではありません。
char command{'A'};
```

## 宣言・定義・初期化・代入

```cpp
// 変数を定義し、生成時に100で初期化します。
int hp{100};

// すでに存在するhpへ80を代入します。初期化とは別の処理です。
hp = 80;
```

## 波括弧初期化を基本にする理由

```cpp
// 小数から整数への狭窄変換をコンパイル時に拒否できます。
// int damage{12.5}; // エラー

// =を使う初期化では変換が許され、情報を失う可能性があります。
int damage = 12.5; // 通常は12になる。警告設定によって警告されます。
```

## ゲーム開発での注意

- HPと座標を同じ`int`だからと混同しないよう、命名や独自型を検討します。
- フレーム時間や座標の`float`を`==`で安易に比較しません。
- オーバーフロー、符号付き・符号なし整数の混在、単位の混在に注意します。
- 初期化されていないローカル変数を読むと未定義動作になる場合があります。
