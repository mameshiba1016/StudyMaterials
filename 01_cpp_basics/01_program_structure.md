# C++プログラムの構造と読み方

## 最小構成

```cpp
// 標準出力ストリームstd::coutの「宣言」を利用するため、標準ヘッダーiostreamを取り込みます。
// #で始まる行は通常のC++文ではなく、コンパイル前にプリプロセッサが処理します。
#include <iostream>

// mainは、ホスト環境で動くC++プログラムの開始地点となる特別な関数です。
// intはmainが呼び出し元の実行環境へ整数の終了状態を返すことを表します。
// ()は関数の引数リストです。ここでは引数を受け取らない形です。
int main()
{
    // stdは標準ライブラリの名前空間、::はスコープ解決演算子、coutは標準出力ストリームです。
    // <<は右側の値を左側のストリームへ挿入します。
    // "Hello, C++!\n"は文字列リテラルで、\nは改行文字です。
    std::cout << "Hello, C++!\n";

    // 0は正常終了を表す慣習的な終了コードです。
    // C++ではmainの末尾へ到達するとreturn 0;が暗黙に行われますが、学習中は明示します。
    return 0;
}
```

## 記号の読み方

| 記号 | 呼び方 | 主な意味 |
|---|---|---|
| `#` | ハッシュ | プリプロセッサ指令の開始 |
| `< >` | 山括弧 | 標準・検索パス上のヘッダー指定など |
| `( )` | 丸括弧 | 関数の引数、条件、評価順の指定など |
| `{ }` | 波括弧 | ブロックや初期化リスト |
| `::` | スコープ解決演算子 | 名前が属する範囲を指定 |
| `<<` | 左シフト／挿入演算子 | 文脈によりビットシフトまたはストリーム挿入 |
| `;` | セミコロン | 文の終端 |

## 内部で起きること

OSは`.cpp`を直接実行しません。プリプロセス、コンパイル、アセンブル、リンクを経て実行ファイルが作られます。起動時にはOSのローダーが実行ファイルと必要なライブラリを仮想メモリへ配置し、C++ランタイムの初期化などを経て`main`が呼ばれます。`std::cout`へ渡した文字はストリームの状態やバッファリングを経由し、最終的にOSの出力機能へ渡されます。
