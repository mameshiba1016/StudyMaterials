# コンパイルとリンク

## ビルドの段階

1. **プリプロセス**：`#include`、`#define`、条件付きコンパイルを処理します。
2. **コンパイル**：C++の構文・型を検査し、各翻訳単位を低水準表現へ変換します。
3. **アセンブル**：機械語を含むオブジェクトファイルを生成します。
4. **リンク**：複数のオブジェクトファイルとライブラリのシンボルを結び、実行ファイルを作ります。
5. **ロード**：実行時にOSがプログラムをメモリへ配置します。

## エラーの分類

- コンパイルエラー：構文違反、型不一致、宣言が見つからないなど。
- リンクエラー：宣言は見つかったが定義がない、同じ定義が複数あるなど。
- 実行時エラー：実行中のアクセス違反、例外、リソース不足など。
- 論理エラー：動くが期待した結果にならないバグ。
- 未定義動作：C++規格が結果を規定しない操作。クラッシュだけでなく、一見正常に動く場合もあります。

## `.h`と`.cpp`

ヘッダーには共有したい宣言、`.cpp`には主な定義を置くのが基本です。`#include`はファイルをリンクする命令ではなく、概念的にはプリプロセス時に内容を取り込む処理です。関数や変数の実体を最終的に結び付けるのはリンカーです。
