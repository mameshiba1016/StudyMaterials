# 反復処理（ループ）

反復処理は同じ種類の仕事を繰り返します。ゲームでは敵一覧の更新、弾の描画、固定ステップ物理、探索などで不可欠です。

## `while`

繰り返し回数が事前に決まらず、条件が成立する間続ける場合に使います。

```cpp
int hp{100};

// 各反復の開始前に条件を評価します。最初からfalseなら一度も実行しません。
while (hp > 0)
{
    hp -= 30;

    // HPが負になる仕様を避けるなら、減算処理側で0へクランプします。
    if (hp < 0)
    {
        hp = 0;
    }

    std::cout << hp << '\n';
}
```

条件に関係する値が変化しなければ無限ループになります。ゲームのメインループは意図的な長期ループですが、終了要求を処理できなければウィンドウが閉じられません。

## `do while`

本体を最低一回実行してから条件を評価します。

```cpp
int selection{};
do
{
    std::cin >> selection;
} while (selection < 1 || selection > 3);
```

末尾の`;`を忘れない点に注意します。

## 古典的な`for`

初期化、継続条件、更新を一か所へまとめます。

```cpp
// iは0、1、2、3、4の順に変化し、本体は5回実行されます。
for (int i{0}; i < 5; ++i)
{
    std::cout << "Enemy index: " << i << '\n';
}
```

- `int i{0}`：ループ開始時に一度だけ実行。
- `i < 5`：各反復前に評価。falseなら終了。
- `++i`：各反復の本体終了後に実行。

コンテナの添字は0から始まることが多く、要素数`N`に対して有効範囲は`0`から`N - 1`です。`i <= N`と書くと範囲外へ一回進む典型的なオフバイワンエラーになります。

## 範囲`for`

全要素を順番に扱い、添字が不要な場合に適します。

```cpp
std::vector<int> enemyHitPoints{100, 80, 120};

// const int&により、要素を変更せず、不要なコピーも避けて読み取ります。
for (const int& enemyHp : enemyHitPoints)
{
    std::cout << enemyHp << '\n';
}

// int&は元の各要素への参照なので、コンテナ内の値を変更します。
for (int& enemyHp : enemyHitPoints)
{
    enemyHp -= 10;
}
```

小さな`int`は値コピーでも通常問題ありませんが、参照の意味を示す例です。参照と`vector`は後続ノートで詳しく扱います。

## `break`と`continue`

```cpp
for (int index{0}; index < 10; ++index)
{
    if (index == 2)
    {
        continue; // 今回の残りを飛ばし、次の反復へ進む。
    }

    if (index == 7)
    {
        break; // 最も内側のループを終了する。
    }

    std::cout << index << '\n';
}
```

`break`は入れ子になったすべてのループを終了するわけではありません。複雑な脱出条件では関数化、フラグ、アルゴリズムを検討します。

## コンテナ更新中の削除

反復中に`vector`などの要素を削除すると、イテレータや参照が無効化される場合があります。範囲`for`内で安易に削除してはいけません。erase-removeイディオム、`std::erase_if`、削除予約、逆順添字など、コンテナと要件に適した方法を選びます。

## 性能上の観点

ループ回数だけでなく、各反復のメモリアクセス、分岐、関数呼び出し、アロケーションが性能へ影響します。ただし、推測で複雑化せずプロファイラで計測します。連続メモリを順に読む処理はCPUキャッシュを活用しやすく、ゲームの大量オブジェクト処理で重要です。
